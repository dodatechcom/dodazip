What Is DodaZIP?

DodaZIP is a cross-platform compression tool that combines deduplication, Reed-Solomon error correction, and XChaCha20-Poly1305 encryption into a single archive format — while also reading and writing 14 foreign formats including ZIP, 7z, RAR, tar, gz, bz2, and xz. It ships with a desktop GUI (Tauri + React) and a full-featured command-line interface.

Key Features

What makes DodaZIP different from every other compression tool

Content-Defined Deduplication

DodaZIP's killer feature. Across-file dedup with FastCDC chunking. If the same file (or duplicate blocks) appears in the input, it's stored only once — no other archiver does this at the archive level.

Self-Healing ECC

Reed-Solomon erasure coding repairs damaged archives automatically. Choose Low (~25% overhead), Medium (~50%), or High (~100%) — if parts of your archive get corrupted, DodaZIP can reconstruct them.

Military-Grade Encryption

XChaCha20-Poly1305 AEAD cipher with Argon2id key derivation. 24-byte nonces, authenticated encryption, GPU-resistant KDF — filenames, metadata, and contents are all encrypted.

Modern Codecs

Zstandard (Zstd), LZMA2 (7-Zip engine), LZ4, and Store. DodaZIP achieves significantly better compression than traditional .zip deflate while keeping speed competitive.

Reads & Writes 14 Formats

Native .dodaz, plus ZIP, 7z, RAR (read-only), tar, tar.gz, tar.bz2, tar.xz, gz, bz2, xz. DodaZIP acts as a universal archiver — one tool for everything.

Desktop GUI + CLI

Polished Tauri desktop app (Linux, Windows, macOS) with dark mode, keyboard shortcuts, breadcrumb nav, right-click context menus. Plus a full CLI for scripting and headless servers.

Random-Access Extraction

Extract a single file from a .dodaz archive in O(1) time — no need to decompress the entire archive. The chunk table gives direct offsets to every chunk.

Open Source & Auditable

MIT / Apache 2.0 dual-licensed. Built in Rust for memory safety. No black boxes — the entire codebase is on GitHub for review, audit, and contribution.

Why DodaZIP Is a Revolution in Compression

What Makes It Different?

  • Deduplication is built in. Every other archiver treats files independently. DodaZIP's FastCDC chunking finds identical chunks across files — so 100 nearly-identical VM images, log files, or database snapshots take barely more space than one.
  • Your archives heal themselves. Reed-Solomon parity means a scratched hard drive or corrupted download doesn't destroy your data. DodaZIP reconstructs lost chunks automatically.
  • Encryption that's actually modern. XChaCha20-Poly1305 + Argon2id is the state of the art — used by WireGuard, macOS, and modern crypto libraries. No aging AES-CBC or weak KDFs.
  • One tool, every format. Read and write ZIP, 7z, RAR, tarballs, and single-file compresses — all from the same GUI or CLI. No more juggling six different tools.
  • Written in Rust. Memory safety without garbage collection. No buffer overflows, no use-after-frees. This matters for a tool that handles your critical data.

The Paradigm Shift

Compression tools haven't fundamentally changed in 30 years — ZIP format dates to 1989, gzip to 1992. They treat each file as an island. DodaZIP asks:

  • "What if the archiver understood that your backup today is 99% identical to yesterday's?" → Dedup handles it.
  • "What if your archive gets damaged?" → ECC repairs it.
  • "What if you want maximum compression without learning codec jargon?" → Segmented buttons (Fastest / Normal / Maximum / Store).
  • "What if you need to encrypt without worrying about which algorithm is safe?" → XChaCha20-Poly1305, no options to get wrong.

The result: A compression tool designed for the 2020s, not the 1990s.

Built for the Rust Ecosystem — Performance That Scales

DodaZIP is a native Rust library, not a GUI wrapper around CLI tools. This means every performance optimization the Rust ecosystem offers is directly available.

Multi-Threaded Deduplication

Rust's Rayon data-parallelism library enables chunking and hashing across all CPU cores. Future DodaZIP releases will split large filesets across threads for near-linear speedup on multicore systems — no other archiver has thread-safe dedup at this level.

SIMD-Accelerated ECC

Reed-Solomon erasure coding is a perfect SIMD target. The reed-solomon-simd crate achieves ~4,500 MB/s encode throughput on modern x86-64 with AVX2 — over 18× faster than the scalar implementation. DodaZIP will integrate SIMD ECC for zero-overhead self-healing.

Streaming Encryption for Giant Archives

Rust's zero-cost abstractions enable encrypting archive data in a streaming fashion — process archives of any size without loading everything into RAM. BLAKE3 hashing and XChaCha20 encryption operate on-the-fly as chunks are compressed, keeping memory constant.

FUSE + Async I/O

Rust's async ecosystem (tokio) combined with FUSE bindings enables mounting .dodaz archives as browsable filesystems with concurrent read-ahead. No C++ archiver offers this — it's uniquely enabled by Rust's memory-safe async runtime.

Zero-Copy Deserialization

Future versions will use Rust's serde with zero-copy deserialization for the archive index, eliminating parsing overhead on large archives. Combined with memory-mapped I/O, opening a multi-GB archive will feel instantaneous.

WASM Compilation

DodaZIP's core library compiles to WebAssembly via wasm-pack. Run dedup-compression in the browser without plugins or servers. No other archiver's engine can do this — PeaZIP (Pascal) and 7-Zip (C++) cannot target WASM.

Why this matters vs. PeaZIP: PeaZIP is built in FreePascal / Lazarus and functions as a GUI frontend that orchestrates external CLI tools (7z, p7zip, Brotli, Zstd, FreeArc, PAQ, etc.). This means PeaZIP inherits the performance characteristics, memory models, and security profiles of those external binaries — it cannot optimize across them. DodaZIP is a single native Rust library where every subsystem (chunking, compression, encryption, ECC, index) shares the same memory allocator, thread pool, and SIMD targets. There is no IPC overhead, no redundant I/O, no duplicated data in memory.

Frequently Asked Questions

Common questions about DodaZIP's technology, compatibility, and use cases

What is the .dodaz format? ▼
.dodaz is DodaZIP's native archive format. It bundles compressed data chunks (using Zstd, LZMA2, or LZ4), a deduplication chunk table, optional XChaCha20-Poly1305 encryption, and optional Reed-Solomon ECC parity. The format supports random-access extraction — you can pull a single file without decompressing the whole archive. A .dodaz file is self-contained; no separate metadata files needed.
Can I open existing .zip / .7z / .rar files with DodaZIP? ▼
Yes. DodaZIP can read and list the contents of ZIP, 7z, RAR (including RAR5), tar, tar.gz, tar.bz2, tar.xz, gz, bz2, and xz files. It can extract all of them. For writing, it supports all of the above except RAR (the format is proprietary and no open Rust library exists for writing).
How does deduplication work? ▼
DodaZIP uses FastCDC (Fast Content-Defined Chunking), which splits files into variable-sized chunks at content-defined boundaries. If the same chunk appears in multiple files (e.g., shared libraries, repeated log entries, duplicate blocks in VM images), it's stored only once. The chunk table maps each file's logical chunks to their physical locations. This is far more effective than file-level dedup — it catches duplicate data at the sub-file level.
Is deduplication lossless? ▼
Absolutely. Deduplication is a purely lossless process. Every byte is verified by BLAKE3 hash before storage. When you extract, each chunk is validated against its hash — if a chunk is corrupted (and ECC is enabled), DodaZIP can even repair it. The decompressed data is bit-for-bit identical to the original.
What platforms are supported? ▼
DodaZIP runs on Linux (x86_64, aarch64), Windows (x86_64), and macOS (x86_64, Apple Silicon). The CLI works on all three. The Tauri GUI works on all three with native look and feel. Memory requirements depend on compression settings — minimum ~256 MB RAM for basic usage, ~1 GB recommended for maximum compression with dedup on large filesets.
How does DodaZIP compare to BorgBackup or restic? ▼
Borg and restic are backup tools — they manage snapshots, incremental backups, and remote repositories. DodaZIP is a compression archiver — it creates standalone archive files you can store, email, or upload anywhere. Unlike Borg/restic, DodaZIP doesn't require a repository or database — a .dodaz file is a single portable file. Use Borg/restic for full backup pipelines; use DodaZIP for ad-hoc archiving, sharing, and distribution. They complement each other.
Can I use DodaZIP in scripts / CI/CD pipelines? ▼
Yes. The CLI binary (`dodazip compress`, `dodazip extract`, `dodazip list`) works in any shell, Docker container, or CI environment. It supports stdin/stdout mode, JSON output for machine parsing, and all compression/encryption/ECC options via flags. No X server or desktop environment is needed — the CLI has no GUI dependencies.
Can I mount a .dodaz archive as a filesystem? ▼
Yes — on Linux with FUSE support. Build with the fuse feature flag, then run dodazip mount --archive archive.dodaz --mount-point /mnt/archive. You can browse the archive as a normal directory. Press Ctrl+C to unmount. This is an optional feature that requires libfuse3-dev at build time.
What compression levels are available? ▼
The GUI simplifies this to a four-button segmented control: Fastest (LZ4, quick but less compression), Normal (Zstd level 10, best all-around balance), Maximum (Zstd level 22 + LZMA2, best ratio), and Store (no compression, for incompressible data). The CLI gives you full control over codec and level independently.
How does DodaZIP compare to PeaZIP? ▼
PeaZIP is an excellent open-source archiver with support for 200+ formats, but it's architecturally very different from DodaZIP. PeaZIP is a FreePascal GUI that orchestrates external CLI tools (7z, p7zip, Brotli, Zstd, FreeArc, PAQ, etc.) — it does not have its own compression engine. DodaZIP is a single native Rust library with a unified engine. Key differences: (1) DodaZIP has content-defined deduplication across files — PeaZIP has none; (2) DodaZIP has Reed-Solomon ECC for self-healing — PeaZIP has none; (3) DodaZIP's engine compiles to WebAssembly — PeaZIP's Pascal codebase cannot; (4) DodaZIP has FUSE mount — PeaZIP does not; (5) DodaZIP's Rust engine provides memory safety guarantees that Pascal/C++ cannot match. Use PeaZIP if you need to extract exotic/legacy formats; use DodaZIP if you need dedup, ECC, modern crypto, and maximum compression in a single native tool.
Is it really free? ▼
Yes. DodaZIP is open source under the MIT and Apache 2.0 licenses — no paid tiers, no subscription, no telemetry. You can use it for personal or commercial projects without restriction. Contributions, bug reports, and feature requests are welcome on GitHub.
